Predicting Bank Term Deposit Subscriptions using Machine Learning

A binary classification pipeline to predict term-deposit subscriptions from the Bank Marketing dataset (~41k observations), benchmarking four classical ML models end-to-end.

Key Features:

  • Benchmarked 4 models: Logistic Regression, k-NN, Decision Tree, and Random Forest after extensive preprocessing and class-imbalance analysis
  • Best: tuned Random Forest (n_estimators=200, max_depth=20, min_samples_leaf=5) with ROC-AUC ≈ 0.81 and F1 ≈ 0.52 on the minority class
  • Feature importance, learning curves, and threshold analysis highlighted campaign history, client attributes, and macroeconomic conditions as key drivers
  • Practical recommendations for class imbalance, temporal robustness, and real-world deployment interpretability
Python Scikit-learn Pandas Matplotlib Random Forest Classification

CNN for Automatic Classification of Martian Surface Features

A convolutional neural network classifying Martian geological features from NASA HiRISE orbital imagery — 8 classes, 73k images, with severe class imbalance handled end-to-end.

Key Features:

  • 4-block CNN with batch normalisation, L2 regularisation, dropout, and data augmentation to handle class imbalance across 8 geological classes
  • Achieved test accuracy of 94% and weighted F1 = 0.93, with excellent generalisation and minimal overfitting
  • Dataset: 73,031 HiRISE images (craters, dunes, spiders, and more) with severe inter-class imbalance
  • Demonstrates robust computer vision on a real-world scientific multi-class imbalanced dataset
Python TensorFlow Keras CNN NASA HiRISE Computer Vision

MLP Regression for Predicting Atmospheric Nitrate Concentration

A Multi-Layer Perceptron predicting weekly atmospheric nitrate (TOTAL_NO3) from 159,602 records of US EPA CASTNET dry deposition data, outperforming a linear baseline significantly.

Key Features:

  • Preprocessing: log transformation, median imputation, standardisation, one-hot encoding, and chronological train/val/test split to prevent data leakage
  • 4-hidden-layer MLP (256–128–64–32) trained with Huber loss yielding R² = 0.8739, RMSE = 0.2806, MAE = 0.2061 on held-out 2020–2025 data
  • Significantly outperformed linear regression baseline (R² = 0.6033) on a 40-variable environmental dataset
  • Temporal robustness validated via strict chronological splitting across 159,602 records
Python TensorFlow MLP Huber Loss EPA CASTNET Regression
⚛️

MLFF Lab — From Quantum Mechanics to Machine Learning Force Fields

End-to-end assessed notebook training, validating, and deploying a machine-learning force field (MLFF) using MACE-torch and the Atomic Simulation Environment (ASE) — mirroring the lifecycle of modern ML interatomic potentials.

Key Features:

  • Data inspection: examined energy and force distributions in reference datasets to understand how dataset diversity determines model reliability
  • Model training: trained an equivariant MLFF using MACE, exploring cutoffs, local environments, and hyperparameter effects on energy/force fitting
  • Validation: assessed model performance with error metrics and parity plots, distinguishing interpolation from extrapolation regimes
  • ASE deployment: integrated the trained MLFF as an ASE calculator into established atomistic simulation workflows
  • Molecular dynamics & analysis: ran MD simulations, analysed energy conservation, trajectories, and structural observables to evaluate MLFF suitability for predictive simulation
Python MACE-torch ASE ML Force Fields Molecular Dynamics Computational Chemistry
